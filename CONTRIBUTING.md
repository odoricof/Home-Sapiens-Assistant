# Contributing to Home-Sapiens-Assistant

Thank you for your interest in this project.

## Feedback and Suggestions

Bug reports, feature requests, ideas, and suggestions are welcome.

Please use GitHub Issues to share:
- Bugs
- Improvement ideas
- New feature requests
- Compatibility reports
- Questions related to the integration

## Pull Requests Policy

Pull Requests may be reviewed, but acceptance is entirely at the maintainer's discretion.

Submitting a Pull Request does not guarantee inclusion in the project.

The maintainer may:
- Accept it
- Request changes
- Rework it internally
- Decline it without merging

## Development Direction

Project architecture, roadmap, and implementation decisions are managed by the maintainer.

## Respectful Collaboration

Please keep discussions constructive, clear, and respectful.

## Thank You

Your feedback helps improve the project.
